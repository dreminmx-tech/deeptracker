# deeptracker

Минималистичный трекер привычек для СДВГ-мозга. Чёрно-белый, офлайн-first, без аккаунтов и без сети.
Один статический сайт — можно залить на GitHub Pages и поставить на телефон как приложение.

```
npm install
npm run dev        # http://127.0.0.1:5173
npm test           # 25 тестов: логика (серии, статистика, импорт/экспорт) + рендер всех экранов
npm run build      # typecheck + сборка в dist/
npm run preview    # посмотреть собранную версию на http://127.0.0.1:4173
npm run icons      # перегенерировать PNG-иконки
```

Проверить, что сервер реально отдаёт статику (в dev и в preview):

```bash
node scripts/smoke.mjs                            # dev на :5173
node scripts/smoke.mjs http://127.0.0.1:4173/     # собранная версия
```

### Если браузер пишет «не удаётся установить соединение»

Адрес берётся строго из вывода Vite (`➜ Local:`). Vite может занять другой порт,
если 5173 уже кем-то занят: например, в другом терминале остался старый `npm run dev`
(закрывается по `Ctrl+C`).

В конфиге явно указан `host: '127.0.0.1'`. По умолчанию Vite биндится на `localhost`,
что на Windows может резолвиться в IPv6-loopback `::1`, и браузер, идущий на `127.0.0.1`,
получает отказ соединения. Если открыть `http://127.0.0.1:5173/` — попадёшь наверняка.

## Что внутри

**Типы привычек**

| Тип | Поведение |
| --- | --- |
| Отметка | Сделано / не сделано, один тап |
| Счётчик | Цель в день (8 стаканов), кнопки −/+ |
| Минуты | Цель по времени + таймер, минуты накапливаются |
| Не делать | Чисто по умолчанию, отмечаются только срывы |
| Гибкая частота | Например, 3 раза в неделю, чипы `1/3 за неделю` |

**Механики под СДВГ**

- **Мягкие серии** («не пропускай дважды»): один пропущенный день не обнуляет прогресс, ломают только два подряд. Сегодняшний незакрытый день вообще не считается пропуском.
- **«Главное сегодня»** — максимум три привычки наверху, остальные ниже: меньше паралича выбора.
- **«Просто начни»** — таймер на 2 минуты с минимальной версией привычки, вместо целого дела.
- **Брейн-дамп** — быстрый инбокс мыслей на сегодня.
- **Статистика без осуждения** — heatmap 7×N, серая шкала, никакого красного; пустая клетка просто пустая.
- **Крупные тап-таргеты** (44px+), монохром, без анимаций-праздников.

**Данные**

Всё лежит в `localStorage` браузера под ключом `deeptracker.v1`. Наружу не уходит ничего.
Бэкап и перенос между устройствами — экспорт/импорт JSON в настройках (файл или вставка текста).
Импорт защищён нормализатором: битый или чужой JSON не сломает приложение.

## Палитра

Тёмная тема собрана по цветам дашборда DeepSeek Platform (снято пиксельно), светлая — строго чёрно-белая.
Все цвета живут в `src/styles.css` в двух блоках: `:root` (тёмная) и `[data-theme='light']` (светлая),
имена токенов одинаковые, поэтому правила стилей написаны один раз.

| Токен | Тёмная | Где используется |
| --- | --- | --- |
| `--bg` | `#141418` | фон страницы |
| `--surface` | `#1c1c1f` | поля ввода, чипы, нижняя навигация |
| `--surface-2` | `#333538` | карточки, модалка |
| `--surface-3` | `#3d4044` | выполненная карточка |
| `--line` / `--line-strong` | `#2b2c30` / `#43454a` | разделители / границы интерактивных элементов |
| `--fg` / `--muted` | `#f8f8fc` / `#a2a6b3` | основной / вторичный текст |
| `--pill` / `--pill-ink` | `#43454a` / `#fff` | активная вкладка |
| `--accent` | `#0070f3` | прогресс-бар, галочка, фокус |
| `--action-bg` / `--action-ink` | `#679efe` / `#0d1117` | основные кнопки |
| `--accent-soft` / `--accent-bright` | `#34415b` / `#cfe0ff` | баннер-подсказка |
| `--good` | `#22c55e` | закрытая неделя, успешный импорт |
| `--warn` | `#d5a51c` | частичный день, мягкое предупреждение |
| `--cell-done` / `--cell-partial` / `--cell-line` | `#679efe` / `#d5a51c` / `#5a5e66` | клетки heatmap |

Красного в палитре нет намеренно: пустая клетка — просто пустая клетка.
Контраст всех пар (текст на фоне, подписи кнопок, клетки heatmap) проверен по WCAG — не ниже 4.5:1 для текста
и 1.5:1 для линий графика.

## Деплой на GitHub Pages

Живая версия: **https://dreminmx-tech.github.io/deeptracker/** — ставится на телефон как приложение.

Быстрый путь (нужен авторизованный [gh](https://cli.github.com)):

```bash
git init -b main
git add . && git commit -m "deeptracker"
gh repo create deeptracker --public --source=. --remote=origin
gh api -X POST repos/<user>/deeptracker/pages -f build_type=workflow
git push -u origin main
```

Дальше всё делает workflow: прогоняет тесты, собирает проект и публикует `dist/` на каждый пуш в `main`
(ручной запуск — через **Actions → Deploy to GitHub Pages → Run workflow**).

<details>
<summary>Вручную, без gh</summary>

1. Создай репозиторий и запушь код в ветку `main`:
   ```bash
   git init
   git add .
   git commit -m "deeptracker"
   git branch -M main
   git remote add origin https://github.com/<user>/<repo>.git
   git push -u origin main
   ```
2. На GitHub: **Settings → Pages → Source: GitHub Actions**.
3. Workflow `.github/workflows/deploy.yml` сам прогонит тесты, соберёт проект и опубликует `dist/`.

</details>

Сборка использует `base: './'`, поэтому один и тот же `dist/` работает и на project-странице
(`https://<user>.github.io/<repo>/`), и на user-странице, и на своём домене — переписывать пути не нужно.

## PWA и офлайн

- `public/manifest.webmanifest` + иконки (генерируются скриптом `npm run icons` без внешних зависимостей).
- `public/sw.js` — service worker: навигация network-first (свежий деплой подхватывается сразу), остальное stale-while-revalidate.
- Регистрация только в production-сборке и только по http(s): с `file://` офлайн-режим не включается.
- **Меняешь оболочку** (иконки, манифест, sw) — подними `CACHE_VERSION` в `public/sw.js`.
- Установка: Chrome/Android — кнопка «Установить на устройство» в настройках; iOS — «Поделиться» → «На экран „Домой“».

## Структура

```
src/
  types.ts            типы данных (Habit, Entry, DayLog, AppData)
  store.tsx           React-контекст + запись в localStorage
  App.tsx             оболочка: вкладки, тема, переключение языка
  styles.css          вся монохромная тема (CSS-переменные, dark по умолчанию)
  lib/
    date.ts           локальные ключи дат YYYY-MM-DD, недели, форматирование
    habits.ts         чистая логика: статусы, мягкие серии, агрегаты
    actions.ts        чистые мутации состояния
    storage.ts        localStorage, нормализация, экспорт/импорт
    i18n.ts           словари ru/en + стартовый набор привычек
  components/         Today / Habits / Stats / Settings + карточки, таймер, модалки
scripts/make-icons.mjs  PNG-иконки (свой мини-энкодер на zlib, без зависимостей)
```

Логика в `src/lib/*` не зависит от React и DOM — она покрыта тестами в `src/lib/habits.test.ts`.
